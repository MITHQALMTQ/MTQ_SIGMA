### 2.2 The exact production design gap (why the prototype is NON-PRODUCTION) — file:line inventory

The production architecture **cannot express this lifecycle today**. Every layer hard-codes a fixed basket, and two constraints make exits inexpressible on-chain at all:

1. **Static 7-currency literal union + record** — `src/lib/mtq/currency.ts:5` (`type CurrencyCode = "USD"|"EUR"|"GBP"|"JPY"|"CNY"|"CHF"|"XAU"`) and `:15-23` (`CURRENCIES` record). Membership cannot change without a type change.
2. **Hard-coded genesis registry whose members ARE the basket instruments** — `src/lib/mtq/registry.ts:57-115` (`genesisRegistry()` returns a literal 9-record array; there is no candidate/watch/eligible/excluded currency registry — validation doc §2: `NOT IMPLEMENTED`).
3. **`!== 7` length throw in the index** — `src/lib/mtq/chain-index.ts:236-241` (`initChainIndex` throws unless exactly 7 components; index init/advance/commit paths are all length-guarded).
4. **Fixed genesis vector** — `src/lib/mtq/genesis.ts:120-128` (literal 7-entry `priorComponents`, 1e-9 genesis sum check) — genesis over a *registered set* does not exist.
5. **Fixed MASE domain** — `src/lib/mtq/mase.ts:10-11` (`type Component = "USD"|"EUR"|"JPY"|"GBP"|"CNY"|"CHF"|"Gold"` + `COMPONENTS` array) — the optimizer's domain cannot change at runtime.
6. **Fixed blueprint arrays** — `src/lib/mtq/blueprint.ts:22-30` (`STRATEGIC_PRIOR`), `:55-62` (`BASE_FIXINGS` incl. the CHF 1.13 fix and XAU 2500), `:78-96` (`ADMISSIBILITY_ENVELOPES` + `ENVELOPES_TABLE`), `:241-244` (`MAX_VELOCITY` per-component classes) — all keyed by the fixed 7 labels.
7. **Honest self-attestation** — `src/lib/mtq/honest-status.ts:245`: "Constituency is STATIC (the 7-component set) … The §4 eligibility scoring … is not live". **This statement remains true of the production system; this prototype does not change it.**
8. **Positive-weights-only submission (the exit blocker)** — `contracts/MTQSigmaV2.sol:518-555` (`submitTargetWeights`: positivity `:526` `if (!(target[i] > 0)) revert Err62()`; exact sum `:529`; per-component floor-division smoothing `:542-547` with no final re-normalization) and `MTQSigmaV3.sol:1310-1342` (positivity `:1317`). A departing component can never reach 0 on-chain, so **no exit transition is expressible at all** (baseline §5 Stage C row 3; spec §5.4 records this as the BLOCKER). The prototype implements the required semantics (excluded ⇒ exactly 0; floors never apply to non-ACTIVE) — production contracts do not.
9. **Fixed contract shapes** — `MTQSigmaV2.sol:298` / `MTQSigmaV3.sol:288` (`bytes3[7] public COMPONENTS`), `uint256[7]` envelope/velocity arrays, immutable `Q_*`/`BASE_*` constants; `setEnvelopes(uint256[7],uint256[7])` (`MTQSigmaV2.sol:560-564` / `MTQSigmaV3.sol:1344-1348`) is the ONLY basket-shape control and cannot change the count; commit tolerance ±1e14 (`MTQSigmaV2.sol:627-638` / `MTQSigmaV3.sol:1384-1388`); all loops `i < 7`.
10. **Deployed v1.2 pilot (DEVELOPER-REPORTED for deployed-ness; source read this session)** — `contracts/MtqEcosystem.sol:143` (`targetGoldWeight = 0.2625e18`) and `:159` (`require(w >= 0.22e18 && w <= 0.30e18)`): the deployed 5-currency pilot hard-codes gold at 26.25% with legacy ±3% clamps — a different economic family (C-INV-2) that cannot be parameter-migrated into a registry model.
11. **Eligibility data feeds do not exist** — BIS/AREAER/vendor ingestion, scoring provenance tiers (spec §2), and the ≥2-independent-family oracle precondition (unmet even for existing legs — honest-status D-oracle-witnesses; deliverable 10) are prerequisites for honest T2 confirmation; none exists in the codebase.
12. **Succession machinery is a read-only swap drill, not this lifecycle** — `chain-index.ts:546-562` (`renormalizeExcluding` / `replaceComponent`) implement the §5.4 redistribution arithmetic the prototype reuses *by convention*, but with instant-at-seed admission, disclosed as not-live (`honest-status.ts:245`).
