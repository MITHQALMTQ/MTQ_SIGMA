## API contract consumed (the P1-A contract)
- `GET /api/ai/briefing` → `{ briefing: string, generatedAt: number, model: string, sources: string[], disclaimer: string }`
- `POST /api/ai/qa` (body: `{ question: string }`) → `{ answer: string, citations: string[], model: string, disclaimer: string }`
- `GET /api/ai/risk-signals` → `{ signals: Array<{ severity: 'critical'|'warning'|'info', title: string, detail: string, source: string }>, generatedAt: number, model: string }`

## Component 1 — AIPolicyBriefing.tsx
- State: `{ briefing, generatedAt, model, sources, disclaimer } | null`, `loading`, `error`.
- `fetchBriefing = useCallback` GETs `/api/ai/briefing`. Mount → fetch once. Then poll every 60s (the backend caches 60s anyway).
- Manual refresh button (top-right, `RefreshCw` icon with `animate-spin` while loading).
- Header: gold eyebrow `AI · COO Briefing` (with `Sparkles` icon), title `Monetary Policy Briefing`, subtitle `Generated by Gemini from the live snapshot. Informational only — not financial advice.`
- Top-right: model badge Pill (gold for real `gemini-2.0-flash`, muted for `fallback-rules`, rose for `error`/`disabled`).
- Body: briefing text rendered as separate paragraphs (split on `\n\n`); every paragraph the model returns is shown, never truncated. `whitespace-pre-wrap` + `leading-relaxed` + `text-[0.85rem]` for readability.
- Footer: `Generated {fmtAgo(generatedAt)} · Sources: {sources.join(', ')}` (with gold GlowDot + mono tabular-nums) + the disclaimer in a small muted line.
- Loading skeleton: 3 gray pulsing `Skeleton` bars.
- Error state: rose-tinted panel with the error message + a Retry button.
- `model === 'disabled'` → amber-tinted panel `AI briefing disabled by feature flag` with a brief explanation of the `AI_BRIEFING_ENABLED` flag.
- Framer-motion `AnimatePresence` keyed by `generatedAt` so a fresh briefing fades in cleanly.
- The component NEVER throws on a 500 — the `try/catch` flips the error state and renders the rose panel.
- `className` prop is spread onto the outer `Panel`.

## Component 2 — BlueprintQA.tsx
- State: `question`, `answer`, `citations`, `model`, `disclaimer`, `loading`, `error`, `history` (Array of `{ q, a, citations }`, capped at 5).
- Submit handler POSTs `/api/ai/qa` with body `{ question }`. On success: sets the current answer, prepends to history (keep last 5), clears the input.
- Input validation: question trimmed, max 500 chars (with `{n}/500` counter; turns amber at 90%, rose at the cap). Submit disabled when empty or loading.
- Header: gold eyebrow `AI · Blueprint Q&A` (with `BookOpen` icon), title `Ask the Blueprint`, subtitle `Gemini-powered Q&A over the v1.0 Master Blueprint constants. Informational only.`
- Model badge Pill top-right (gold for real Gemini, muted for fallback, rose for error/disabled).
- History list: small bordered cards — question in `text-amber-200/90`, answer in `text-foreground/90` with `whitespace-pre-wrap`, citations as small muted mono pills (`§{citation}`). `max-h-72 overflow-y-auto` with the custom `mtqs-scroll` scrollbar.
- Current answer panel (when loading or just-submitted): large bordered panel with `border-mtqs-gold/25 bg-mtqs-gold/[0.04]`. Answer text in `whitespace-pre-wrap leading-relaxed text-[0.82rem] text-foreground/95`. Citations row: small gold Pills prefixed by `§`. Disclaimer footer (small muted line under a top border).
- Loading state inside the answer panel: 3 pulsing gray `Skeleton` bars.
- Error state inside the answer panel: rose-tinted panel + Retry button (re-submits the trimmed question).
- Input area: a 2-row textarea + `Send` button. Mobile-first stacks vertically; sm+ side-by-side.
- Char counter right-aligned, color-coded (muted → amber at 90% → rose at 500).
- Suggested questions row: 3 small clickable chips (`What is the GFB Index?`, `How does the §9 oracle consensus work?`, `What are the admissibility envelopes?`) — only shown when `history.length === 0 && !loading && !answer && !error`. Clicking fills the input AND immediately submits.
- Keyboard: Enter submits, Shift+Enter inserts a newline (textarea default).
- Auto-scroll the history to the bottom when a new answer arrives (useRef + `scrollIntoView`).
- `className` prop is spread onto the outer `Panel`.

## Component 3 — RiskSignals.tsx
- State: `{ signals, generatedAt, model } | null`, `loading`, `error`.
- `fetchSignals = useCallback` GETs `/api/ai/risk-signals`. Mount → fetch. Then poll every 15s (Groq is fast; the live snapshot updates every 4s).
- Manual refresh button top-right.
- Header: gold eyebrow `AI · Risk Signals` (with `Activity` icon), title `Live Risk Monitor`, subtitle `Generated by Groq (llama-3.3-70b) from the live snapshot. Informational only.`
- Top-right: model badge Pill (gold for `llama-3.3-70b-versatile`, muted for `fallback-rules`, rose for `error`/`disabled`).
- Signal list: each signal is a row card with:
  - Severity icon: `critical` = rose `AlertCircle`, `warning` = amber `AlertTriangle`, `info` = muted `Info`.
  - Severity badge Pill (with GlowDot): `critical` = rose `CRITICAL`, `warning` = amber `WARNING`, `info` = muted `INFO`.
  - Title (bold, `text-foreground/95`) + detail (muted, `text-muted-foreground/85`, smaller).
  - Source: small mono, uppercase tracking, right-aligned (e.g. `oracle`, `concentration`, `peg`, `buffer`).
  - Left border colored by severity (rose / amber / white) for a quick visual scan.
- `AnimatePresence` wraps the list so signals fade-in + slide-down on change.
- Empty state: a single muted row `No signals emitted` (with a gold GlowDot).
- Footer: `Generated {fmtAgo(generatedAt)} · {signals.length} signals` (with gold GlowDot + mono tabular-nums) + disclaimer `AI-generated. The engine math (src/lib/mtq/engine.ts) is the source of truth.`
- Loading skeleton: 2 pulsing gray rows (each with a `Skeleton` h-3 w-1/3 + h-2.5 w-[80%]).
- Error state: rose-tinted panel with the error + Retry button.
- `max-h-[28rem] overflow-y-auto` on the signal list with custom `mtqs-scroll` scrollbar.
- `className` prop is spread onto the outer `Panel`.

## Shared design choices
- All 3 components have a `modelTone(model)` helper that maps:
  - `gemini-2.0-flash` / `llama-3.3-70b-versatile` / `dbmdz/...` (any real model) → `gold`
  - `fallback-rules` / `fallback-regex` → `muted`
  - `disabled` / `error` → `rose`
- All 3 use `Panel + Reveal` from primitives, lucide-react icons (NO emojis), and the brand palette only (`text-mtqs-gold`, `text-amber-200/90`, `text-rose-300`, `text-muted-foreground/85`, `border-white/[0.07]`, `bg-white/[0.02]`, `bg-mtqs-gold/[0.04]` etc.). NO indigo, NO blue.
- `font-mono tabular-nums` on all numeric/timestamp output.
- Mobile-first throughout: stack on small screens, side-by-side (or right-aligned) on sm+.
- The components NEVER throw on a 500 — they catch and flip to the error state.
